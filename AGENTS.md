# Standing project instructions

## UI colour palette

- User preference: everything in the application UI must be a shade of blue. Apply this to all future visual changes in this repository unless the user explicitly changes the preference.
- Use blue-tinted surfaces, navy/blue text, blue borders, icons, buttons, status indicators, focus rings, shadows, and error/notification treatments. Do not introduce green, orange, red, purple, or neutral grey UI accents.
- Keep the shared `--blue-*` design tokens in `aiKnowledgeChatAssistant/frontend/src/style.css` as the source of truth for application colours. Preserve readable contrast and distinguish states with text/icons/borders as well as blue shades.
- Original PDF source content keeps its original appearance so evidence remains faithful; do not recolour research-paper page images.
